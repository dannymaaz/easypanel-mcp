# Security Policy

## Supported versions

Security fixes are provided for the latest stable release. Older releases may not receive patches.

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities.

Use GitHub's private vulnerability reporting for this repository when available. If that option is unavailable, email **hola@dannymaaz.com** with:

- the affected version and platform;
- reproducible steps or a minimal proof of concept;
- the expected and observed behavior;
- the potential impact;
- any suggested mitigation.

Do not include real credentials, personal data, or destructive payloads. You will receive an acknowledgement as soon as practical, followed by coordinated remediation and disclosure when appropriate.

## Scope

Reports concerning exposed secrets, unsafe file or command handling, authentication bypasses, dependency vulnerabilities, and unintended destructive behavior are in scope. General support questions and feature requests should use GitHub Issues.
